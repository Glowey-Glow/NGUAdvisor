# Default Zone Stats for Sniping

NGU Advisor picks the best gold-snipe zone from these built-in Power/Toughness thresholds. For a zone:
if your **Manual** thresholds are met it snipes a boss without fast combat; if the **Idle** thresholds
are met it snipes with fast combat (Beast Mode off). **One-shot Power** is the attack needed to one-shot
the zone (used for boost-farm zone selection).

Override any zone in zoneOverrides.json (in `%UserProfile%\AppData\LocalLow\NGUAdvisor`). Do **not**
edit the shipped defaultZoneStats.json — updates overwrite it.
